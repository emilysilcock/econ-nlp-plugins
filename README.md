# econ-nlp-plugins

A [Claude Code](https://code.claude.com) plugin marketplace for economics & NLP research workflows.

## Usage

Add the marketplace once:

```text
/plugin marketplace add emilysilcock/econ-nlp-plugins
```

Then install any plugin from it:

```text
/plugin install agentic-clustering@econ-nlp-plugins
```

To update later:

```text
/plugin marketplace update econ-nlp-plugins
/plugin update agentic-clustering@econ-nlp-plugins
```
